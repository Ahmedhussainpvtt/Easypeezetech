# EasyPeeze Technologies (production)

React + Vite + Framer Motion site for [easypeezetech.com](https://easypeezetech.com/).

## Deploy

```powershell
npm install
npm run push
```

- **main** = React source
- **gh-pages** = built site (GitHub Pages + custom domain)
- **backup/static-seo-20261021** = previous static HTML SEO site

## Local

```powershell
npm run dev
```
